# LeetCode Questions Company Wise

Curated lists of LeetCode questions grouped by company, sorted by frequency. This repository contains CSV files for each company with problems asked in technical interviews, organized by time ranges (1 year, 2 years, 6 months, all time).

## Format

Each CSV file contains:
- Problem title
- LeetCode problem link
- Frequency/occurrence count
- Difficulty level

## Usage

Browse the CSV files by company name. Files are named as `{company}_{timeframe}.csv`.

## Companies Included

Adobe, Airbnb, Amazon, Apple, Atlassian, Bloomberg, Cisco, Dropbox, Facebook/Meta, Google, IBM, Intel, LinkedIn, Microsoft, Netflix, Oracle, PayPal, Salesforce, Samsung, Spotify, Tesla, Twitter/X, Uber, Visa, Walmart, Zoom, and 150+ more.

## Note

This is a read-only dataset. For solutions, refer to the main LeetCode repository.
